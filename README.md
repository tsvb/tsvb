#### Things I've built

| Project | What it does |
|---|---|
| [**Post Peek**](https://github.com/tsvb/post-peek) | Chrome extension that opens x.com links in a popup so you can read one post without cookies being sent to X. [Linked on Daring Fireball](https://daringfireball.net/linked/2026/09/12/post-peek). |
| [**Lutzy**](https://github.com/tsvb/lutzy) | Applies `.cube` LUTs to RAW and DNG photos on the Mac, and turns a camera's JPEG look back into a LUT. |
| [**EchoScribe**](https://github.com/tsvb/EchoScribe) | Records, transcribes, and summarizes meetings on-device with Apple Intelligence. |
| [**PhotoDrop**](https://github.com/tsvb/PhotoDropMac) | Verified photo ingest for macOS: every byte is hash-checked, duplicates are skipped, and nothing is overwritten. |
| [**It Is Always DNS**](https://github.com/tsvb/itisalwaysdns) | A native macOS DNS troubleshooting tool for lookups and leak tests. |
| [**flatlink**](https://github.com/tsvb/flatlink) | Shows every photo in a folder tree in one DxO PhotoLab grid. |
| [**AppleNugs**](https://github.com/tsvb/applenugs) · [**nugs.net for Windows**](https://github.com/tsvb/nugsdotnet) | Unofficial nugs.net players for Mac/iPhone and Windows. |
| [**Goose Index**](https://www.gooseindex.com) | A statistics almanac for the band Goose. |

PhotoDrop and flatlink install from my Homebrew tap: `brew install --cask tsvb/tap/photodropmac` or `brew install --cask tsvb/tap/flatlink-app`.
